## 👋 About me

I'm **Anas Gara**, a software engineer bringing an application developer's perspective to cloud infrastructure and DevOps. My work spans web and mobile development, AWS architecture, infrastructure as code, and delivery automation.

I enjoy connecting the pieces: how a service is built, how it gets deployed, how it scales, and how to understand it when something goes wrong. My repositories explore those questions through Terraform infrastructure, serverless event processing, and containerized Java services.
